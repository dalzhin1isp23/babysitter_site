# Babysitter Site

Учебный веб-проект сайта, посвящённого услугам няни.

Проект представляет собой статический многостраничный сайт с отдельными страницами, стилями, изображениями и JavaScript-логикой.

## Возможности

* главная страница;
* навигация между страницами;
* информационные блоки;
* оформление интерфейса с помощью CSS;
* использование изображений и других медиаматериалов;
* JavaScript для интерактивных элементов страницы.

## Структура проекта

```text
babysitter_site/
├── css/             # Стили проекта
├── image/           # Изображения
├── pages/           # Дополнительные страницы сайта
├── js/              # JavaScript-логика
├── index.html       # Главная страница
└── index.css        # Основные стили
```

## Технологии

* HTML5
* CSS3
* JavaScript

## Запуск

Проект не требует установки зависимостей.

Для запуска достаточно открыть файл:

```text
index.html
```

в браузере.

Для более удобной разработки рекомендуется использовать расширение Live Server в VS Code.
